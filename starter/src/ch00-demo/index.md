# Demonstration

This chapter is the template's documentation, written as a chapter so that it is built, checked and rendered exactly like real content. Its one section uses every environment the config declares, on mathematics chosen to be trivial: even and odd integers, and nothing else. Read the built page and the Markdown source side by side.

Delete `src/ch00-demo/` before the book has a second chapter, and take the `chapters` entry in `config/config.json` out with it. Nothing else in the repository refers to it.

**What you need:** nothing. The section assumes only that you know what an integer is.

**Roadmap:**

- *Every Environment* — one worked page that exercises every block, cross-reference, display, table, figure and exercise group the engine supports, each introduced by a line saying what it is for and what its markup is.

**Named moves:** a chapter's `index.md` normally ends with the proof techniques the chapter introduces, so a reader can carry them forward. This one introduces none.
